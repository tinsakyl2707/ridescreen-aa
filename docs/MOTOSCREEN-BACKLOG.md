# MotoScreen TH — งานที่ตัดสินใจแล้ว รอแก้รวมรอบเดียว

## B1 · สลับภาษาแล้วค้าง (พบใน v9, 3 พ.ย. 2026) — ตัดสินใจ: A + B · ✅ แก้ใน v10
**อาการ:** กดปุ่ม TH | EN แล้วหน้าจอค้างไปช่วงหนึ่ง
**สาเหตุ (จากโค้ด):**
- หน่วงเอง 240 ms ก่อนเรียก `setApplicationLocales`
- Android สร้าง MainActivity ใหม่ทั้งหน้า และ onCreate/onResume รันงานเหมือนเปิดแอปครั้งแรก
  (ถอดรูปรถบน main thread, maybeAutoConnect, maybeCheckUpdate, ถามสิทธิ์/WhatsNew)
- ไม่มี transition ระหว่างหน้าเก่ากับหน้าใหม่

**แก้ A — ให้สร้างหน้าใหม่เบาลง**
- ตั้ง flag "recreated for language" (static/companion) ก่อน setLang
- ถ้า flag นี้ตั้งอยู่: ข้าม maybeAutoConnect, maybeCheckUpdate, maybeAskNearbyUpfront,
  Xiaomi autostart, WhatsNew/Telemetry และ wizard check
- ย้ายการถอดรูป hero (BitmapFactory) ไปทำบน background thread แล้วค่อย set บน UI
- ลดหน่วง 240 ms → ~120 ms

**แก้ B — แอนิเมชันจางออก/จางเข้า**
- ตอนกด: thumb เลื่อน + content (R.id.main) alpha 1→0 ภายใน ~150 ms แล้วเรียก setLang
- หลังสร้างใหม่ (มี flag): content เริ่มที่ alpha 0 แล้ว animate → 1 ภายใน ~200 ms
- ทำใน SetupWizardActivity ด้วย (มีปุ่มภาษาในหน้าแรกของ wizard)

**ต้องเช็คตอนแก้:** สลับภาษาตอนกำลังฉายภาพอยู่ ภาพบนจอรถต้องไม่สะดุด
(projection อยู่ใน service แต่ต้องดูว่า MainActivity.onDestroy ไม่ไปหยุดอะไร)

**ยังรอจากผู้ใช้:** ค้างนานกี่วินาที / ตอนนั้นต่อจอรถอยู่ไหม / log รอบที่กด

**แก้แล้วใน v10:** flag `MotoScreen.langSwitching` (หมดอายุเอง 5 วิ), ข้าม auto-connect / update / prompts / wizard,
รูป hero ถอดเบื้องหลัง + cache ข้ามการสร้างหน้าใหม่, จางออก 140 ms → จางเข้า 200 ms (หน้าแรก + wizard),
onDestroy ไม่ teardown การเชื่อมต่อถ้าเป็นการสร้างหน้าใหม่ (isChangingConfigurations)

## B3 · สัดส่วน UI — ✅ แก้ใน v11 (H1–H5, S1–S3, M1–M3, D1–D2)
ที่ผมเห็นเองจากรูปก่อนหน้า:
- [ตั้งค่า] ปุ่มคู่ เปิด|ปิด ใหญ่เท่าปุ่มตัวเลือก (เชื่อมต่อเองเมื่อเปิดแอป, บันทึกทริป) → เปลี่ยนเป็นสวิตช์แถวเดียว
- [ตั้งค่า] หัวข้อการ์ด (เทาเล็ก) vs ชื่อตัวเลือก (ขาวใหญ่) vs คำอธิบาย: ระยะห่างไม่เท่ากัน → ตั้ง spacing 4/8/16/24 ชุดเดียว
- [ทริป] ปุ่มเต็มความกว้าง 3 อัน (ไฟแดง / สัปดาห์นี้ / นำเข้า GPX) + ปุ่มกลม Year/All → รวมเป็นแถวชิปเดียว
- [ทริป] การ์ดทริป: ป้าย DISTANCE ตัวพิมพ์ใหญ่ ขนาดไม่เท่าป้ายอื่น, ปุ่ม แชร์/GPX สูงเกิน
- [บำรุงรักษา] ทุกรายการมีปุ่มใหญ่ 2 ปุ่ม → การ์ดสูงมาก → ทำเป็นแถวกะทัดรัด (ชื่อ + แถบความคืบหน้า + "อีก X กม.") แตะเพื่อเปิดรายละเอียด
- [สแกน QR] ปุ่มล่าง 2 ปุ่มสูงไม่เท่ากันเมื่อข้อความตัดบรรทัด → บังคับความสูงเท่ากัน
- [หน้าแรก] การ์ดรถ 190dp ช่วงกลางโล่ง, ทางลัดสูง 108dp ใหญ่กว่าช่องตัวเลข → ปรับให้สัดส่วนสัมพันธ์กัน
- [ทุกหน้า] ปุ่ม Segment สูง/มุมโค้งไม่เท่ากันในแต่ละหน้า → ใช้ style เดียว

### จากรูป v10 (โหมดสว่าง)
**หน้าแรก**
- H1 ทางลัด 4 ช่องสูงไม่เท่ากัน: "ทริปของฉัน" มีบรรทัดรอง (🔥 ขี่ติดกัน 2 วัน · 1 today) → ช่องเดียวสูงกว่า
  → ตัดบรรทัดรองออกจากทางลัดทั้งหมด, ความสูงตายตัว, ชื่อสั้นเท่ากัน ("ทริป")
  → "1 today" ยังเป็นอังกฤษ (plurals home_tile_trips_today) แปลด้วย
- H2 ไอคอนน้ำหนักไม่เท่ากัน: ประแจเป็นแบบทึบ อีก 3 อันเป็นเส้น → วาดประแจใหม่เป็นเส้น
- H3 การ์ดรถ: ชื่อ "Zontes 368G" ทับเส้นเกจ, ป้าย "● MOTOSCREEN LINK" ซ้ำซ้อน
  → ย้ายเกจไปมุมขวาล่างเล็กลง/จางลง, เปลี่ยนป้ายเป็นสถานะสั้น หรือเอาออก
- H4 สถานะ "พร้อม" + จุดเทา: ดูเหมือนปิดอยู่ → ตอนพร้อมใช้จุดสีหลัก, คำว่า "พร้อมเชื่อมต่อ"
- H5 ช่อง "＋ ตั้งบำรุงรักษา": เครื่องหมาย + ใหญ่กว่าตัวเลขข้างๆ → ใช้ขนาดเดียวกับตัวเลข หรือข้อความ "ตั้งค่า"
**ตั้งค่า**
- S1 "🎯 ปรับภาพให้พอดีจอรถ" เป็นข้อความลอยกลางการ์ด มีช่องว่างด้านบนเยอะ → ทำเป็นแถวกดได้ (ไอคอน + ข้อความ + ›)
- S2 ปุ่มคู่ เปิด|ปิด (เชื่อมต่อเองเมื่อเปิดแอป, บันทึกทริป) → สวิตช์แถวเดียวแบบ "เสียงแจ้งเมื่อเชื่อมต่อ"
- S3 "🆘 ตรวจจับการล้ม" ข้อความลอยกลาง → แถวกดได้แบบ S1
**บำรุงรักษา**
- M1 การ์ดสูงเพราะปุ่มใหญ่ 2 ปุ่ม × 8 รายการ → แถวกะทัดรัด: ชื่อ + แถบความคืบหน้า + "อีก X กม."; แตะแถว = เมนู ทำแล้ว/แก้ไข
- M2 ข้อความ "แตะ "แก้ไข" เพื่อใส่ว่าทำครั้งล่าสุดเมื่อไร" ซ้ำทุกการ์ด → บอกครั้งเดียวด้านบน
- M3 หน่วย "km" → "กม." ตามภาษา (Maintenance.fmtKm)
**หมอแอป**
- D1 เซิร์ฟเวอร์เครื่องเสียงขึ้น ⚠️ ทั้งที่เปิดอยู่จริง (รูป AA เมนูมี "หยุดเซิร์ฟเวอร์…" = กำลังทำงาน)
  สาเหตุ: Android ไม่ให้แอปเห็นว่าเซิร์ฟเวอร์เปิดอยู่ (probe คืน null) → อย่าแสดงเป็นคำเตือน;
  แสดงเป็น ℹ️ "เช็คเองไม่ได้" ท้ายรายการ หรือเป็น ✅ ถ้าเคยต่อสำเร็จหลังเปิดเครื่องครั้งนี้
- D2 หัวข้อ dialog ยังเป็นฟอนต์ระบบ (ไม่ใช่ Kanit)

## B5 · แจ้งราคาน้ำมันล่าสุด (ขอ 3 พ.ย. 2026 10:10)
- น้ำมันที่ผู้ใช้เติม: **แก๊สโซฮอล์ 95** และ **E20** (โชว์ทั้งสองชนิด, ให้เลือกชนิดหลักได้)
- ปั๊มประจำ: **บางจาก** → ราคาหลักจากบางจาก; ปตท./OR เป็นแหล่งสำรองเท่านั้น
- แหล่งข้อมูล: บางจาก (หลัก) + ปตท./OR (สำรอง) — ⚠️ endpoint ยังไม่ได้ยืนยันว่ายังใช้ได้ ต้องทดสอบจากมือถือ;
  ดึงไม่ได้ = บอกตรงๆ ห้ามโชว์ราคาเก่าเป็นราคาล่าสุด (แสดงเวลาที่ดึงได้ล่าสุดเสมอ)
- หน้าแรก: ช่องราคา (ชนิดหลัก) + ลูกศรถ้าพรุ่งนี้ขึ้น/ลง
- แจ้งเตือน: เช็ควันละครั้งตอนเย็น เตือนเฉพาะเมื่อราคาพรุ่งนี้เปลี่ยน ("พรุ่งนี้ 05:00 ขึ้น 0.50 ฿ · เติมวันนี้ถูกกว่า")
- เต็มถังประมาณกี่บาท (ขนาดถังใส่เองได้)
- ปุ่ม "⛽ เติมน้ำมันแล้ว" ในบำรุงรักษา: เติมราคาต่อลิตรให้เอง
- ยังรอ: เวลาเตือน (ใช้ 18:00 ถ้าผู้ใช้ไม่ระบุ)
